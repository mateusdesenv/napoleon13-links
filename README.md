# Napoleon13 — Link page

Página de links estática com tema inspirado em Minecraft para o streamer Napoleon13.

## Estrutura

- `public/index.html` — conteúdo da página
- `public/styles.css` — identidade visual e responsividade
- `public/script.js` — compartilhamento da página
- `public/` — arquivos publicados pela Vercel

Pode ser aberta diretamente no navegador ou publicada em qualquer hospedagem estática.
